What is CSS?

Cascading Style Sheets (CSS)is user to format the layout of a webpage.

With CSS, you can control the color, font,the size or text,the spacing between elements,how elements are
position and laid out ,what background images of background colors are
tobe used diffirent devices and screen sizes,and much more?

Tip:The word cascading mean that a style applied to a parent element will also apply to all children
element within the parent.So,if you set the color of the body text to"blue," all headings,paragraphs,and
other text elements within the body will also get the same color(unless you specify something else)!
